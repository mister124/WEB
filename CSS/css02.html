20. Multicolumn Layout

column-count: 열 개수
column-gap: 열 사이 간격
column-rule: 열 사이 구분선

CSS는 웹페이지의 스타일을 표현합니다. 여러 열을 사용하면 긴 텍스트를 신문처럼 나누어 표시할 수 있습니다. column-count로 열 개수를 지정하고 column-gap과 column-rule을 이용해 간격과 구분선을 설정할 수 있습니다.

21. Media Queries

@media를 이용해 화면 크기 등에 따라 다른 CSS 적용
max-width: 해당 크기 이하
min-width: 해당 크기 이상

화면 너비가 480px 이하이면 1열, 481px~1024px이면 2열, 그보다 크면 기본 3열로 표시됩니다. 브라우저 크기를 변경하면서 확인하면 됩니다.
