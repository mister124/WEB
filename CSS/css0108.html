2. overflow

이 박스는 width가 250px이고 height가 80px로 고정되어 있습니다. 그런데 글자가 계속 길어지면 박스의 크기를 넘어갈 수 있습니다. 이때 overflow: auto를 사용하면 필요한 경우 스크롤바가 나타납니다.

3. Box Model

이 영역이 content입니다. content와 테두리 사이에는 padding이 있습니다.

4. border

border-style = dashed

5. padding

content와 border 사이의 공간이 padding입니다.

6. margin

border 바깥쪽의 공간이 margin입니다.
