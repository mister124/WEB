CSS-1 정리

1. Inline Style

inline style: HTML 요소의 style 속성에 CSS 작성
기본 문법: property: value;

font-size: 20px; color: blue;

2. Embedded Style / Selector

element selector: 태그 이름
class selector: .class
id selector: #id

element selector 적용

class selector 적용

id selector 적용

3. External Style Sheet

외부 CSS 파일을 HTML과 분리하여 작성
연결: <link rel="stylesheet" href="style.css" />

4. Cascade / Inheritance / Specificity

inheritance: 일부 속성이 부모에서 자식으로 전달
specificity: ID > class > element
같은 specificity라면 나중 규칙 우선

부모의 color와 font-family는 상속됨.

직접 지정된 color가 상속보다 우선

#box p가 가장 구체적

같은 specificity면 나중 규칙 적용

underline

overline

line-through

5. Pseudo-class / Length Units

:link: 미방문 링크
:visited: 방문 링크
:hover: 마우스를 올린 상태
:active: 클릭 중인 상태
px: 고정 단위
em: 현재/부모 font-size 기준
rem: html의 font-size 기준
%: 부모 등 기준 비율
vw / vh: viewport 기준

Pseudo-class 확인

24px

20px 부모

1.5em = 30px

1.5rem = 24px

부모의 50%
50vw
10vh

6. position / z-index

static: 기본 배치
relative: 원래 위치 기준 이동
absolute: 가장 가까운 positioned ancestor 기준
fixed: viewport 기준, 스크롤해도 고정
sticky: 스크롤 위치에 따라 고정
z-index: 큰 값이 앞쪽

7. Block / Inline / display

div: 대표적인 block-level 요소
span: 대표적인 inline-level 요소
block: 한 줄 영역 차지
inline: 내용 크기만 차지
inline-block: inline 배치 + width/height 가능
none: 화면과 공간에서 제거

block div 1
block div 2

문장 중 이 부분만 span 적용

inline 2

inline-block 2

display: none

text-align: center

8. Box Model

구조: content → padding → border → margin
padding: content와 border 사이
margin: border 바깥 공간
overflow: 넘치는 내용 처리

width / height
내용이 영역보다 길면 overflow 설정에 따라 스크롤하거나 숨길 수 있습니다. 이 예제는 overflow: auto입니다.
content + padding + border + margin
border: 5px dashed red
margin / padding: top right bottom left

9. Float / Clear

float: 요소를 좌/우로 이동시키고 주변 내용이 흐르게 함
clear: float의 영향을 종료
clear: both: 좌우 float 모두 해제

float: left

텍스트가 왼쪽 float 요소의 오른쪽으로 흐르는 것을 확인할 수 있습니다.

float: right

텍스트가 오른쪽 float 요소의 왼쪽으로 흐르는 것을 확인할 수 있습니다.

float

부모에 overflow: auto를 주어 float 영역까지 포함합니다.

10. Media Types / Media Query

@media print: 인쇄할 때 적용
@media screen: 화면에서 적용
max-width / min-width: 화면 크기에 따라 CSS 변경

이 문장은 인쇄할 때 숨겨집니다.

화면 폭이 600px 이하이면 배경색이 변경됩니다.

11. Drop-Down Menu

평소 submenu는 display: none
부모 li:hover 시 submenu를 display: block으로 변경
