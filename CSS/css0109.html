CSS Float

1. float: left

왼쪽으로
float

이 글은 float가 적용된 박스의 주변으로 흐릅니다. 원래라면 박스 아래에서 시작할 수 있지만, float를 적용하면 박스가 왼쪽으로 이동하고 텍스트가 박스의 오른쪽 공간을 사용할 수 있습니다. 이것이 float의 기본적인 동작입니다.

2. float: right

오른쪽으로
float

이번에는 박스를 오른쪽으로 이동시켰습니다. 따라서 텍스트는 박스의 왼쪽 주변으로 흐릅니다. float: left와 반대 방향으로 생각하면 됩니다.

3. 이미지처럼 사용하기

이미지

웹페이지에서 float는 이미지와 텍스트를 배치할 때 자주 사용되었습니다. 이미지를 왼쪽으로 float시키면 텍스트가 이미지 오른쪽으로 흐르게 됩니다. 이미지 주변에 margin을 주면 글자가 이미지에 너무 붙지 않도록 할 수 있습니다. 이런 방식으로 기사나 소개 페이지의 이미지와 본문을 배치할 수 있습니다.

4. float를 이용한 2단 배치

왼쪽 영역

이 박스와 오른쪽 박스에 모두 float: left를 적용했습니다.

오른쪽 영역

두 박스가 모두 왼쪽으로 float되면서 공간이 허용되는 경우 옆으로 배치됩니다.

clear: both

이 영역부터는 위의 float 요소의 영향을 받지 않도록 했습니다.

5. float와 부모 영역

float

이 박스는 float되어 있습니다. 부모 요소가 float 요소의 높이를 정상적으로 계산하지 못하는 상황이 생길 수 있습니다.
