HTML-2 정리

1. HTML5 Input Types

date: 날짜 선택
number: 숫자 입력
email: 이메일 형식 검사
color: 색상 선택
required: 필수 입력
placeholder: 입력 예시
min / max / step: 숫자 범위와 단위

2. 추가 Input Types / Validation

search: 검색어 입력
tel: 전화번호 입력, 자체 형식 검사는 없음
pattern: 입력 형식 제한
url: URL 형식 검사
range: 범위 슬라이더
time: 시간 선택
datetime-local: 날짜 + 시간
month: 연도 + 월
week: 연도 + 주차

3. autocomplete / datalist / fieldset

autocomplete: 브라우저 자동완성
datalist: 추천값 제공 + 직접 입력 가능
input의 list 값 = datalist의 id 값
fieldset: 관련 form 요소 그룹화
legend: fieldset의 제목

개인정보

4. Semantic Elements

header: 머리말
nav: 주요 탐색 링크
section: 주제별 구역
article: 독립적인 콘텐츠
aside: 보조 내용
figure: 독립적인 자료
figcaption: figure 설명
footer: 하단 정보
time: 날짜/시간 의미 표현

5. details / meter / progress / 기타 요소

details + summary: 내용을 펼치고 접기
meter: 범위 안의 현재 측정값
progress: 작업 진행 정도
mark: 텍스트 강조
wbr: 줄바꿈 가능 위치
iframe: 다른 HTML 문서를 현재 페이지에 삽입
