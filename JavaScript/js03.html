JavaScript-3 정리

while·for·do while → switch → 복리 계산 → break·continue → 중첩 반복

1. 반복문 비교

while 은 먼저 조건 검사, do...while 은 한 번 실행 후 검사, for 는 초기식·조건식·증감식을 한곳에 쓴다.

2. for와 누적

증감식은 i++ 뿐 아니라 i += 2 처럼 바꿀 수 있다.

3. switch

표현식 값과 일치하는 case 부터 실행한다. 보통 break 로 다음 case 실행을 막고, 해당 값이 없으면 default 를 실행한다.

4. 복리·Math.pow·toFixed

Math.pow(base, exponent) 는 거듭제곱, number.toFixed(2) 는 소수점 둘째 자리까지 문자열로 만든다.

5. break와 continue

break 는 반복을 즉시 끝내고, continue 는 현재 회차의 나머지만 건너뛴다.

6. 중첩 반복

반복문 안에 반복문을 넣어 행과 열을 만든다.
