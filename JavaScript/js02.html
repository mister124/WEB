문제를 순서가 분명한 절차로 만들고, 의사 코드로 점검한 뒤 구현한다. 기본 제어 구조는 순차, 선택, 반복이다.

2. if / else if / else

단일 선택, 양자택일, 다중 선택을 표현한다. 블록 중첩 시 어느 if 의 else 인지 중괄호로 명확히 한다.

3. 비교·논리·조건 연산자

동등 비교는 형 변환 없는 === / !== 를 권장한다. 논리 연산자는 AND && , OR || , NOT ! , 조건 연산자는 조건 ? 참값 : 거짓값 이다.

4. while: 카운터 제어 반복

반복 횟수를 알면 카운터를 초기화하고, 조건을 검사하고, 매회 갱신한다.
