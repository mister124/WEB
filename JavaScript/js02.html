JavaScript-2 정리

1. Control Statements

sequence: 순서대로 실행
selection: 조건에 따라 선택 실행
repetition: 조건에 따라 반복 실행

2. if / if...else

if: 조건이 true일 때만 실행
if...else: true / false 중 하나를 실행
아래 실습은 false를 true로 변경하면 실행

3. while

조건이 true인 동안 반복
반복 중 조건과 관련된 값이 변하지 않으면 infinite loop 발생 가능

4. Counter-Controlled Repetition

반복 횟수를 미리 알고 있는 definite repetition.
counter: 반복 횟수를 세는 변수
total: 값을 누적하는 변수
아래 실습은 false를 true로 변경하면 실행

5. Sentinel-Controlled Repetition

반복 횟수를 미리 모르는 indefinite repetition.
sentinel: 입력 종료를 나타내는 특별한 값
아래 실습은 -1 입력 시 종료하며 false를 true로 변경하면 실행

6. Nested Control Statements

control statement 안에 다른 control statement 사용
예: while 안에 if...else
아래 실습은 false를 true로 변경하면 실행

7. Assignment Operators

+=, -=, *=, /=, %=
x += 5는 x = x + 5와 동일

8. Increment / Decrement Operators

++ : 1 증가
-- : 1 감소
a++ : 현재 값 사용 후 증가
++a : 먼저 증가 후 값 사용
