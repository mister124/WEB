JavaScript-5 정리

배열 생성 → index·length → 순회·카운터 → 함수 전달 → join·sort·검색 → 2차원 배열

1. 배열 생성과 동적 크기

new Array(3) 은 값 없이 길이만 3인 배열을 만든다. ["apple", "banana", "orange"] 는 값과 길이를 함께 정한다. JavaScript 배열은 실행 중 추가·삭제되어 크기가 바뀔 수 있다.

2. index와 length

index는 0부터 시작한다. 마지막 요소는 array[array.length - 1] 이다. 대입으로 값을 바꾸고 push / pop 으로 끝에 추가·삭제할 수 있다.

3. 배열 순회와 합계

index가 필요하면 for , 값만 필요하면 for...of 가 알맞다. 배열 index 순회에 for...in 은 보통 사용하지 않는다.

4. 빈도 카운터

주사위 눈을 배열 index로 사용하면 여러 개의 개별 변수나 긴 switch 없이 횟수를 셀 수 있다.

5. 배열에서 임의 요소 선택

Math.floor(Math.random() * array.length) 로 유효한 임의 index를 만든다. 선택 결과는 setAttribute 로 접근성 속성에도 반영한다.

❔

6. 함수에 배열 전달

배열을 함수에 전달하면 같은 배열 객체를 참조한다. 함수에서 요소를 바꾸면 원본도 바뀐다. 숫자 하나를 전달하면 그 값의 복사본을 받는다.

7. join·sort·indexOf·lastIndexOf

join 은 문자열 결합, sort 는 정렬이다. 숫자 정렬에는 비교 함수 (a, b) => a - b 가 필요하다. 검색 실패 시 index method는 -1 을 반환한다.

8. 2차원 배열

배열 안의 배열로 표를 표현한다. matrix[row][column] 처럼 접근하고 중첩 반복으로 순회한다.
