JavaScript-5 정리

1. Array 기본

array: 관련된 여러 데이터를 하나의 이름으로 저장하는 구조
element: 배열의 각 값
index: element의 위치 번호, 0부터 시작
length: 배열의 element 개수

2. new Array / Dynamic Array

new Array(n): 길이가 n인 Array 객체 생성
JavaScript 배열은 생성 후에도 크기가 변할 수 있음
기존 범위 밖 index에 값을 넣으면 배열의 length가 늘어남

3. Initializer List

[] 안에 값을 쉼표로 나열하여 생성 가능
initializer의 값 개수가 배열의 length가 됨

4. Array 순회와 합계

일반 for: index를 0부터 length - 1까지 직접 사용
for...in: 배열의 index를 순회

5. Array Element를 Counter로 사용

각 index를 특정 경우의 횟수와 연결하면 frequency counter로 사용 가능

6. Array로 값 목록 관리

파일명이나 설명처럼 서로 대응하는 값을 배열에 저장하고 random index로 선택 가능

7. Array와 Function

PPT 표현: 배열 전체는 reference로 함수에 전달되어 함수에서 원본 배열을 변경할 수 있음
숫자·boolean 같은 개별 element는 value로 전달

8. join()

join(separator): 배열 element들을 지정한 separator로 연결한 문자열 반환

9. sort()

sort(): 배열 정렬
argument가 없으면 문자열 비교 방식으로 정렬
숫자 정렬은 비교 함수를 전달하는 것이 중요

10. indexOf() / lastIndexOf()

indexOf(value): 앞에서부터 첫 번째 위치 검색
lastIndexOf(value): 뒤쪽의 마지막 위치 검색
찾지 못하면 -1 반환
두 번째 argument로 검색을 시작할 index 지정 가능

11. Multidimensional Array

2차원 배열은 배열 안에 배열을 저장하는 형태
접근: array[row][column]
각 row의 길이는 서로 달라도 됨
