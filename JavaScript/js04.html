JavaScript-4 정리

함수 → 매개변수·인수·return → Math → 이벤트·DOM → setAttribute → toFixed → 스코프·재귀

1. 함수 정의·호출·return

함수는 반복 작업을 묶는다. 정의의 parameter (매개변수)가 호출 때 전달한 argument (인수)를 받고, return 이 결과를 돌려준다. 

function square(number) {
        return number * number;
      }
      let result = square(5);
      // 25

2. Math 객체와 난수

Math.max , Math.min , Math.floor , Math.ceil , Math.round , Math.pow , Math.sqrt , Math.PI 를 확인한다. 주사위 공식은 Math.floor(1 + Math.random() * 6) 이다.

⚀

3. 이벤트 처리와 addEventListener

addEventListener("click", handler) 는 이벤트와 처리 함수를 연결한다. 처리 함수의 event.currentTarget 은 리스너가 연결된 요소다.

4. DOM 속성: setAttribute / getAttribute

element.setAttribute(name, value) 는 HTML 속성을 만들거나 바꾼다. 아래 주사위는 매번 aria-label , data-value , title 을 갱신한다.

5. 숫자 method: toFixed

toFixed(n) 는 숫자를 소수점 아래 n자리로 반올림한 문자열 을 반환한다.

6. 오디오·비디오 요소 제어

미디어 요소의 공통 method는 play() , pause() 이며 currentTime , volume , muted 같은 속성이 있다. 외부 파일 없이 실행되도록 여기서는 진행 표시를 미디어 타임라인처럼 제어한다.

0.0초

7. 지역·전역 스코프

함수 밖 변수는 여러 함수에서 접근할 수 있다. 함수/블록 안의 let 은 그 범위 안에서만 유효하므로 가능한 좁게 선언한다.

8. 전역 함수와 재귀

parseInt , parseFloat , isNaN 는 전역 함수다. 재귀 함수는 자기 자신을 호출하며 반드시 종료 조건이 필요하다.
