JavaScript-4 정리

1. Function 기본

function: 특정 작업을 하나로 묶어 필요할 때 호출
parameter: 함수 정의에서 받는 값
argument: 함수를 호출할 때 전달하는 실제 값
return: 함수의 결과를 호출한 위치로 반환

2. 여러 Parameter와 return

함수는 여러 parameter를 받을 수 있음
return이 실행되면 함수는 즉시 종료되고 결과가 호출 위치로 돌아감

3. Function / Method 호출

function 호출: functionName(argument)
method 호출: object.method(argument)
argument에는 상수, 변수, 표현식 사용 가능

4. Random Number Generation

Math.random(): 0 이상 1 미만의 실수
Math.floor(): 소수점 아래를 버려 정수로 만듦
연속된 정수 범위: Math.floor(a + Math.random() * b)
a: 시작값, b: 가능한 정수의 개수

5. Event Handling / addEventListener

event: 사용자의 클릭·마우스 이동 같은 동작
event handler: event가 발생했을 때 실행되는 함수
addEventListener("event", function): 요소와 handler 연결

6. load Event

window의 load event는 문서 로딩이 끝난 뒤 함수를 실행할 때 사용
형식: window.addEventListener("load", 함수이름, false)

7. HTML5 audio / video

audio/video 요소에 id를 주면 JavaScript에서 요소를 찾아 제어 가능
preload="auto": 필요할 때 바로 재생할 수 있도록 미리 로딩을 고려
source의 src는 파일 위치, type은 MIME type 

<audio id="sound" preload="auto" controls>
  <source src="sound.mp3" type="audio/mpeg" />
  <source src="sound.ogg" type="audio/ogg" />
</audio>

<video controls>
  <source src="rules.mp4" type="video/mp4" />
</video>

8. Scope Rules

global scope: 함수 밖에서 선언되어 여러 함수에서 접근 가능
local scope: 함수 내부의 변수와 parameter, 해당 함수 안에서만 사용
같은 이름의 local 변수가 있으면 함수 안에서는 global 변수가 가려짐

9. JavaScript Global Functions

isFinite(): 유한한 숫자인지 확인
isNaN(): 숫자가 아닌 값인지 확인
parseFloat(): 문자열 앞부분을 실수로 변환
parseInt(): 문자열 앞부분을 정수로 변환

10. Recursion

recursion: 함수가 자기 자신을 다시 호출
base case: 재귀를 끝내는 가장 단순한 경우
recursion step: 더 작은 문제로 자기 자신을 다시 호출

11. Recursion vs. Iteration

iteration: 반복문으로 반복, 조건이 false가 되면 종료
recursion: 반복적인 함수 호출, base case에 도달하면 종료
종료 조건이 잘못되면 infinite loop / infinite recursion 발생
