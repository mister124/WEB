JavaScript-1 정리

1. First Script

script: JavaScript 코드 영역
document: 현재 HTML 문서 객체
writeln(): HTML 문서에 내용 출력

2. write / 문자열 연결 / alert

write(): HTML 문서에 출력
+ : 문자열 연결
alert(): 팝업 출력
\n : 문자열 안 줄바꿈
아래 실습은 false를 true로 변경하면 실행

3. prompt / 변수

let: 변수 선언
prompt(): 사용자 입력
= : 오른쪽 값을 왼쪽 변수에 대입
아래 실습은 false를 true로 변경하면 실행

4. Adding Integers

prompt()의 입력값은 문자열
parseInt(): 문자열을 정수로 변환
아래 실습은 false를 true로 변경하면 실행

5. Arithmetic

+ : 덧셈
- : 뺄셈
* : 곱셈
/ : 나눗셈
% : 나머지

6. Decision Making

if: 조건이 true일 때 실행
== : 같은지 비교
!= : 같지 않은지 비교
>, <, >=, <= : 크기 비교
아래 실습은 false를 true로 변경하면 실행
