JavaScript-1 정리

스크립트 → 출력 → 변수·자료형 → 입력·변환 → 연산자 → 조건문

1. script와 출력

JavaScript는 <script> 내부 또는 src 로 연결한 외부 파일에 작성한다. 주석은 // , /* ... */ 다. 예제 원본의 document.write() 는 로딩 후 문서를 지울 수 있어 여기서는 DOM 출력을 사용한다.

2. 변수·상수·자료형

let 은 재할당 가능, const 는 재할당 불가다. 주요 자료형은 string, number, boolean, undefined, null, object다. 

let score = 80;
      score = 90;
      const course = "Web";

3. 입력·문자열·숫자 변환

input.value 는 문자열이다. 정수는 parseInt , 실수는 parseFloat 또는 Number 로 변환한다.

4. 산술·대입·비교 연산자

산술 + - * / % ** , 대입 = += -= *= /= , 비교 === !== < > <= >= 를 사용한다. 문자열 결합에도 + 가 쓰이므로 숫자 변환이 중요하다.

5. if / else와 시간

조건식이 참이면 if , 거짓이면 else 블록을 실행한다. new Date().getHours() 는 현재 시각의 시간을 반환한다.
