탐구 1 — 어떤 규칙이 적용되는가
같은 요소에 적용되는 일반 CSS 규칙은 선택자 우선순위가 높은 선언이 먼저 적용된다.
tbody tr td는 td보다 우선순위가 높아서, 뒤에 작성된 빨간색 규칙보다 먼저 작성된 파란색 규칙이 적용됐다.
선택자 우선순위가 같으면 나중에 작성한 선언이 적용된다.
개발자 도구에서는 다른 선언에 밀려 적용되지 않은 선언에 취소선이 표시된다.

탐구 2 — max-width와 width
width: 960px은 화면이 좁아져도 요소의 폭을 960px로 지정한다.
max-width: 960px은 최대 폭만 제한하므로, body는 좁은 화면에서 사용할 수 있는 폭에 맞춰 줄어든다.
따라서 화면 크기가 다양한 환경에는 max-width가 더 적합하다.
